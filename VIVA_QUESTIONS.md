# Viva Questions and Short Answers

1. What is Spring Boot?
Spring Boot simplifies Spring application development using auto-configuration, starters and embedded servers.

2. Why use REST API?
REST provides a standard HTTP-based interface between frontend and backend.

3. What is JPA?
Java Persistence API is a specification for mapping Java objects to relational database tables.

4. Why MySQL?
It is a popular relational database suitable for structured application data.

5. What is JWT?
JSON Web Token is used here to authenticate API requests without server-side HTTP sessions.

6. What is @Entity?
It tells JPA that a Java class represents a database entity.

7. What is @ManyToOne?
It represents a many-to-one relationship, such as many appointments belonging to one doctor.

8. What is CORS?
Cross-Origin Resource Sharing controls browser requests between different origins.

9. What is Postman?
A tool used to send HTTP requests and test REST APIs.

10. How is double booking prevented?
Before saving an appointment, the backend checks whether the same doctor already has an appointment at the same date and time.
